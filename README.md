# LangChain Agents: jsonParser + ReAct with local LLM

Проект демонстрирует подход к созданию **интерактивного агента с
поддержкой рассуждений и инструментов**, работающего полностью на
локальной языковой модели в формате GGUF.

Агент реализован с использованием **ReAct-подхода** (Reasoning + Acting)
и способен выполнять действия во внешней среде (например, искать
информацию), опираясь на рассуждения модели.

## Реализовано

-   **Запуск локальной LLM** через `llama-cpp-python` (Colab GPU + модель GGUF)
-   Генерация ответа на основе имеющегося контекста с помощью:
    - **Шаблонов промптов**
-   Анализ отзывов товаров с помощью:
    -   **Цепочки обработки** с использованием LCEL (`|`) и `LLMChain`
    -   **Парсинг JSON-ответов** через `JsonOutputParser`
-   **ReAct-агент** с актуальными знаниями
    -   **Интеграция инструмента поиска** (`DuckDuckGo`)

## Используемые технологии

-   [`LangChain`](https://github.com/langchain-ai/langchain)
-   [`llama-cpp-python`](https://github.com/abetlen/llama-cpp-python)
-   `duckduckgo-search`

## Результат

1. Настроена локальная LLM
2. Решена задача анализа отзывов на товары: извлечение имён продуктов, ключевых характеристик и пользовательских оценок
3. Разработан ReAct-агент, способный рассуждать и выполнять действия с помощью внешнего инструмента — поиска DuckDuckGo

## Возможные доработки

-   Подключение `Memory` для сохранения истории диалога
-   Интеграция `ChromaDB` или `FAISS` для retrieval и RAG
-   Расширение набора инструментов (`Tools`)
-   Обёртка в интерфейс (например, `Streamlit`)
